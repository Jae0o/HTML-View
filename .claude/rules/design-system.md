# 디자인 시스템 (v1.0.0)

화면이 들어가는 모든 작업은 시작하기 전에 `custom-design-system` Skill 을 먼저 읽는다. 코드뿐 아니라 목업 · 와이어프레임 · 시안 · 프로토타입, 기획 · 분석 문서 안의 화면 그림도 해당한다.
Skill 은 jae0-fe 플러그인에 있다(`jae0-fe:custom-design-system`). 저장소 `.claude/skills/` 에는 두지 않는다.

1. `references/00-시작.md` 를 먼저 읽고, 그 문서의 읽는 순서와 행동 규칙을 따른다.
2. 목록 두 개(`references/foundations/INDEX.md` · `references/components/INDEX.md`)에서 이번 작업에 맞는 본문만 골라 읽는다.
3. 주변 코드나 첨부 화면과 Skill 문서가 다르면 Skill 문서를 따른다.
4. 문서에 없는 값은 지어내지 않고 확인 대상에 기록한다.
5. 작업 끝에 「사용한 규칙」 · 「확인 대상」 O/X 목록을 남긴다.
