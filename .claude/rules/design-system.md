# 디자인 시스템 (v0.1.1)

화면 · 컴포넌트 · 스타일 작업을 할 때는 코드를 쓰기 전에 `design-system` Skill 을 먼저 읽는다.
Skill 은 jae0-fe 플러그인에 있다(`jae0-fe:design-system`). 저장소 `.claude/skills/` 에는 두지 않는다.

- Skill 의 `references/00-시작.md` 행동 규칙을 따른다.
- 주변 코드와 Skill 문서가 다르면 Skill 문서를 따른다.
- 문서에 없는 값은 지어내지 않고 확인 대상에 기록한다.
- 작업 끝에 「사용한 규칙」 · 「확인 대상」 O/X 목록을 남긴다.
