# 03 코드 정렬 도구

셋업 결정 3-A 로 진행한다.

## 목표

Prettier 와 Tailwind 클래스 정렬 플러그인을 넣어, `npm run format` 을 실행하면 코드 모양과 클래스 순서가 같아지게 한다. 편집기 저장 시 자동 정렬 설정은 범위 밖이다.

## 단계

1. `npm install -D prettier prettier-plugin-tailwindcss`
2. 저장소 루트에 `.prettierrc` 를 만든다. 코드 모양은 템플릿이 만든 코드와 같게(세미콜론 없음 · 작은따옴표) 맞춰, 정렬을 돌려도 기존 파일 모양이 바뀌지 않게 한다. 저장소 `.claude/docs` 에 다른 규칙이 있으면 그 값을 따른다.

```json
{
  "semi": false,
  "singleQuote": true,
  "plugins": ["prettier-plugin-tailwindcss"],
  "tailwindStylesheet": "./src/index.css"
}
```

3. `package.json` scripts 에 `"format": "prettier --write ."` 를 더한다.
4. `.prettierignore` 를 만들어 저장소 규칙 문서를 정렬 대상에서 뺀다. `dist` · `node_modules` 는 `.gitignore` 를 따라 이미 빠지므로 적지 않는다.

```
.claude
CLAUDE.md
```

## 확인

- [ ] `App.tsx` 를 `className="text-base text-text-brand font-semibold"` 로 두고 `npm run format` 후 `text-base font-semibold text-text-brand` 순서가 된다 (토큰 파일을 읽었다는 뜻)
- [ ] `npm run format` 이 템플릿 파일(`main.tsx` · `vite.config.ts`)에 세미콜론 · 큰따옴표를 넣지 않는다
- [ ] `npx prettier --check src/index.css` 통과 — 02 에서 넣은 모양 그대로다
- [ ] `npx prettier --file-info CLAUDE.md` · `npx prettier --file-info .claude/x.md` 결과가 모두 `"ignored": true` 다 (파일이 없어도 확인 가능)
- [ ] `npm run build` · `npm run lint` 통과
