# 01 프로젝트 생성

## 목표

Vite `react-ts` 템플릿으로 빈 React 앱을 만들고, 0Docs 이름 · 탭 아이콘 · 경로 별칭 · Zustand 설치까지 끝낸다.

## 전제

- 저장소 위치: `~/Develop/HTML-View` (결정 1-A).
- 폴더에 미리 있어도 되는 것: `.git` · `.claude/` · `CLAUDE.md`. 그 밖의 파일이 있으면 아무것도 만들지 말고 무엇이 있는지 보고한다.
- 패키지 매니저: npm (결정 2-A).
- Node: 22.12 이상 (Vite 요구 `^20.19.0 || >=22.12.0`).

## 단계

1. 프로젝트를 만든다. `create-vite` 는 `.git` 만 있는 폴더에서는 그대로 만들고, 다른 파일 · 폴더가 있으면 취소한다. 폴더 상태에 따라 나눈다. `--overwrite` 는 기존 파일을 지우므로 쓰지 않는다.
   - 비어 있거나 `.git` 만 있으면: 저장소 폴더에서 `npm create vite@latest . -- --template react-ts --no-interactive`
   - `.claude/` · `CLAUDE.md` 가 있으면: 옆에 빈 임시 폴더 `../HTML-View-scaffold` 에 같은 명령으로 만든 뒤, 점으로 시작하는 파일(`.gitignore` · `.oxlintrc.json`)까지 저장소 폴더로 옮긴다 — 예: `cp -Rn ../HTML-View-scaffold/. .` (같은 이름 파일이 있으면 멈추고 보고). 옮긴 뒤 임시 폴더를 지우고, `package.json` 의 `name` 을 `html-view` 로 바꾼다.
2. `npm install` 후 `npm install zustand` 로 Zustand 를 설치한다. 스토어 파일은 아직 만들지 않는다.
3. 템플릿 예시를 정리한다. `src/App.tsx` 는 빈 화면 한 줄(`0Docs`)만 남기고, `src/App.css` · `src/assets/` 의 예시 이미지 · `public/` 의 예시 아이콘을 지운다. `src/index.css` 는 비운다 (02 에서 채운다).
4. `index.html` 을 고친다. `lang="ko"`, `<title>0Docs</title>`, 탭 아이콘은 `/favicon.svg`.
5. `public/favicon.svg` 에 로고 마크(시안 A 「접힌 0」)를 넣는다. 원본은 아래 「로고 마크」.
6. 경로 별칭 `@/` → `src/` 를 건다. 별칭 값은 `tsconfig.app.json` 한 곳에만 적고, Vite 가 그 값을 읽게 한다. TypeScript 7 은 `baseUrl` 을 쓰지 않으므로 넣지 않는다.

```jsonc
// tsconfig.app.json — compilerOptions 안에 추가
"paths": { "@/*": ["./src/*"] }
```

```ts
// vite.config.ts — defineConfig 안에 추가
resolve: { tsconfigPaths: true },
```
7. `package.json` 에 `"engines": { "node": ">=22.12" }` 를 넣는다. Vite 가 요구하는 최소 버전이다. Vercel 은 이 조건에 맞는 최신 버전(지금 26.x)으로 빌드한다.

## 확인

- [ ] `grep -o '<title>0Docs</title>' index.html` · `grep -o 'lang="ko"' index.html` 가 각각 한 줄
- [ ] `public/favicon.svg` 가 있고 `#10b981` 을 포함한다
- [ ] `npm run build` 통과 (`tsc -b` 포함)
- [ ] `npm run lint` 통과
- [ ] 경로 별칭이 타입 검사 · 빌드 · 개발 서버 모두에서 동작한다. 임시 파일로 확인하고 끝나면 지운다.

```bash
# 임시: src/lib/probe.ts → export const probe = '0Docs'
# 임시: App.tsx 에서 import { probe } from '@/lib/probe' 하고 화면에 {probe} 출력 (안 쓰면 타입 검사가 실패함)
npm run build                                                   # 기대: 통과
npx vite --port 5173 --strictPort &                             # 개발 서버
sleep 3; curl -s localhost:5173/src/App.tsx | grep -o '/src/lib/probe.ts'   # 기대: 한 줄 (Vite 별칭 설정이 읽혔다는 뜻)
pkill -f 'vite --port 5173'
```
- [ ] `package.json` dependencies 에 `zustand` 가 있다
- [ ] lock 파일은 `package-lock.json` 하나뿐이다
