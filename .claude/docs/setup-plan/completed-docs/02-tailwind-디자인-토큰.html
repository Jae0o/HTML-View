셋업 02 · Tailwind 연결 · 디자인 토큰 완료

허용된 값만 Tailwind 클래스로 만들어지고, 화면 글꼴이 Pretendard 로 바뀌었어요

Tailwind v4 를 연결하고, 기본 값을 모두 지운 다음 디자인 시스템 허용 값과 프로토타입 확정 값만 다시 걸었어요. 그래서 px-3 · rounded-lg · bg-red-500 같은 클래스는 써도 아무 스타일이 생기지 않아요.

2Tailwind 기본 값을 지우고 허용 값만 남겨서, 그 밖의 클래스는 만들어지지 않아요

예시 → 규칙 순서로 볼게요. 확인할 때 App 에 임시로 넣은 클래스 8개가 어떻게 걸러졌는지예요.
임시로 넣은 클래스8개
허용 값에 있는 이름 (나머지 4개는 기본 값을 지워서 만들어지지 않음)4개
CSS 로 만들어진 것 — p-8 · gap-12 · rounded-6 · h-324개
p-8gap-12rounded-6h-32 px-3rounded-lgbg-red-500text-xl
테마로 막지 못하는 클래스는 규칙으로 막아요
p-px · border-2 · rounded-full · 대괄호 px([12px]) · max-w-sm 같은 이름 너비는 빌드하면 만들어지지만 쓰지 않아요. 실행 가이드 「쓰지 않는 클래스」 목록을 따르고, 필요하면 토큰을 먼저 더하자고 보고해요.

3토큰은 다섯 종류이고, 클래스 숫자가 곧 px 값이에요

예: p-8 = 안쪽 여백 8px, rounded-6 = 둥글기 6px. 1rem = 10px 이라 값은 rem 으로 적혀 있어요.
