Prettier 와 Tailwind 클래스 정렬 플러그인을 넣었어요. npm run format 을 실행하면 코드 모양이 템플릿과 같게 유지되고, 클래스는 정해진 순서로 바뀌어요. 화면 모습은 바뀌지 않아요.

1「0Docs」 글자의 클래스 순서만 바뀌었고, 보이는 모습은 그대로예요

화면에 닿는 코드는 이 한 줄뿐이에요. 클래스 순서는 스타일 결과에 영향이 없어서 화면 목업은 02 문서 §1 을 그대로 씁니다.

본문 「0Docs」 의 클래스

text-basetext-text-brandfont-semibold
↓ npm run format
text-basefont-semiboldtext-text-brand

글자 크기 → 굵기 → 색 순서예요. 플러그인이 text-text-brand 가 색 토큰이라는 걸 알아야 이 순서가 나와요. 그래서 이 결과가 「02 의 토큰 파일을 읽었다」 는 확인이 돼요.

2정렬 대상은 앱 코드와 설정 파일이고, 규칙 문서 폴더는 빠져요

npm run format 을 실행한 결과예요. 주황 = 이번에 실제로 바뀐 파일, 흰색 = 이미 정렬된 모양, 회색 = 대상에서 빠진 것.

왜 규칙 문서를 빼나요
플랜 · 완료 문서는 사람이 쓴 문서라 모양을 자동으로 바꾸지 않아요. dist 와 node_modules 는 Prettier 가 .gitignore 를 읽어 이미 빼므로 따로 적지 않았어요.

3설정은 파일 두 개와 명령 하나예요

1
설치 — Prettier 와 Tailwind 클래스 정렬 플러그인 (개발용 패키지)
2
정렬 규칙 파일 — 세미콜론 없음 · 작은따옴표 (템플릿 모양 그대로), 플러그인과 토큰 파일 위치
3
명령 — npm run format 으로 저장소 전체 정렬
4
제외 목록 파일 — .claude · CLAUDE.md
// .prettierrc
{
  "semi": false,
  "singleQuote": true,
  "plugins": ["prettier-plugin-tailwindcss"],
  "tailwindStylesheet": "./src/index.css"
}
편집기 저장 시 자동 정렬은 넣지 않았어요
플랜 범위 밖이에요. 지금은 npm run format 을 직접 실행해야 정렬돼요.
